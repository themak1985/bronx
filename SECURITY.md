# Security policy

## Supported versions

Bronx is currently an alpha project. Security fixes are made against the latest
published release only.

## Reporting a vulnerability

Do not report a suspected vulnerability in a public GitHub issue. Email Bashar
Makhay at <bashar.makhay@gmail.com> with the subject `Bronx security report`.
Include the affected version, impact, reproduction steps, and any suggested
mitigation. Remove personal, payment, and production-site data from reports.

Receipt will be acknowledged when practical. Details should remain private
until a fix or mitigation is available.
