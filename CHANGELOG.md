# Changelog

All notable changes to Bronx are documented here. Versions follow semantic
versioning while the extension remains in active development.

## [0.6.0] - 2026-10-16

### Changed

- Renamed the extension key and installation directory from
  `org.civicrm.bronx` to `bronx`.
- Moved extension files to the repository root for CiviCRM publishing.
- Added public repository, compatibility, maintainer, and support metadata.
- Left-aligned traditional CiviCRM action buttons with their form fields.

### Added

- Standalone public Profile styling and regression fixtures.
- Public workflow coverage documentation.
- Enforced 40 KiB raw and 8 KiB compressed main-stylesheet budgets.

## [0.5.0–0.5.8] - 2026-10-13 to 2026-10-14

Initial private test releases established responsive Profiles, event
registration, contributions, Price Sets, Select2 controls, field-width tiers,
Afform isolation, and mobile behavior.
